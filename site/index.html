      How it works

      Every month India's drug regulator, CDSCO, lists the medicine batches its labs found not of standard quality, or fake. This site joins every list and traces each batch back to the factory that made it.

      1. Collect. Downloads every monthly alert list from CDSCO's website, and the newer lists from its NSQ portal.
      2. Read. Pulls the tables out of the PDFs, in both the old and new layouts, and checks the row count against the totals each list states.
      3. Clean. Standardises medicine names, dates and failure reasons, and finds each factory's state and district from its address and PIN code.
      4. Link. Matches the many spellings of each manufacturer to one company and one factory site.
      5. Store. Loads everything into a DuckDB database in layered SQL tables.
      6. Check. Runs data quality checks on every build.
      7. Predict. Ranks factories by their chance of being flagged next month, and tests that against a simple rule.
      8. Publish. Writes the data files this page reads.

      Data quality

        Limits

        • CDSCO publishes only the batches that failed, not how many each company had tested, so there are no failure rates here.
        • Spurious (fake) batches carry an innocent company's name, so they never count against that company.
        • Some states send no list in some months. A gap means no report, not no failures.
        • The watch list only covers factories flagged before, and predicts where inspectors find failures, not true quality.
